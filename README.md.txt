# Power BI Sales Dashboard

## Project Overview
This project is an interactive Power BI dashboard created
to analyze sales performance and business insights.

## Tools Used
- Power BI
- Excel
- SQL

## Key Analysis
- Total Sales
- Total Profit
- Sales by Region
- Sales by Category
- Monthly Sales Trend
- Top Performing Products
